# Instructions and skills

- Treat the configured instructions and the skills catalog as part of the session's policy. Do not
  restate or override them from a project file.
- Load a skill by its exact ID when its description matches the task. Read only the supporting
  files the skill names.
- Paths written inside a skill are relative to the directory containing its `SKILL.md`.
- A managed instruction or skill path is read-only. Do not try to edit it; report a needed change
  to the owner instead.
