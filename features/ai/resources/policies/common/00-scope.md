# Scope and ownership

- Own the user's intent, important decisions, integration and acceptance in the main conversation.
- In a delegated run, own only the assigned scope and report to the requester. Do not repeat the
  global planning process or create another coordinator.
- Keep dependent steps with one owner. Delegate further only when the assignment needs it.
- Escalate conflicting requirements, out-of-scope architectural changes and blocked work with
  evidence and a precise question.
