# Independent review

Use when a change has enough impact to justify a second reader, or the owner asks for one.

1. Read the change and the acceptance checks, not only the author's summary.
2. Check correctness, scope, preserved user state and failure behaviour.
3. Report findings in severity order with file and line references.
4. State what you inspected and what you did not.
