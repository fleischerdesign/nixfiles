## Lessons

- OpenSSH known_hosts lookup uses the bare host for port 22; a `[host]:22` entry does not match, so a pinned host key for the default port must be written without brackets.
- In Nix indented strings `''` is an escape; `ssh-keygen -N ''` inside `''…''` breaks parsing. Use `-N ""`.
- `pkgs.nixosTest` is now `pkgs.testers.nixosTest` in the pinned nixpkgs.
