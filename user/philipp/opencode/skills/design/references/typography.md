# Typography

## When to load & job

Use this to select and set type for an interface, document, or artwork. Assign faces and settings to the jobs the text actually does, from sustained reading to scanning a table. If the work changes glyph outlines or font behavior, use Type Design instead.

## Inputs

Bring the existing type system, licensed fonts and available weights, real copy for each role, required scripts and languages, and the widths at which people will read. If a font or translation is unavailable, label the substitute and leave line breaks and coverage for that language provisional.

## Decisions & process

- **One family or a pair.** Start with one family when labels, numerals, and body text need to feel related. Add a contrasting face when display text needs a distinct voice the body family cannot give it. That adds another set of metrics and fallback choices. Compare the same title, paragraph, and figures, not two unrelated specimens.
- **Scale, measure, and spacing.** Set body text first at the actual column width. If the eye loses the return to the next line, try a narrower measure before increasing line spacing; the narrower column costs more vertical space. On a narrow screen, step a heading down a size or weight before tightening its tracking just to keep a preferred line break. Compare a short heading with one that wraps naturally.
- **Fallback behavior.** Choose fallback faces by script coverage and how similarly they occupy space. A metrically close fallback can keep a label on one line while losing some visual character; a closer stylistic match may wrap sooner. Show both the primary face and its fallback in the same narrow layout.

## Typical mistakes & examples

A price table inherits proportional numerals from the body style, so the digits drift even with amounts right-aligned. Use tabular figures where magnitudes need to be compared, and keep proportional figures in prose where even-width digits can look loose.

## Deliverables & questions for the human

Show a type specimen with real copy at representative widths, plus the role, spacing, and fallback settings. Ask which languages are required and where compactness matters more than a generous measure.
