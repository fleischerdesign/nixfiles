# Sustainable Design

## When to load & job

Use this for a brief comparing design options with environmental implications. Set up a comparison that a specialist can assess. Material selection or artwork alone cannot establish which option has lower impact.

## Inputs

Gather the service each option provides, the current baseline, expected geography and lifetime, and available supplier, operations, and disposal data. Record each source and whether it represents the actual production context. Without those inputs, draft a boundary diagram and data request; do not substitute generic values and report a result.

## Decisions & process

- Compare the same service, not just the same object. For takeaway containers, start with meals delivered under equivalent conditions, not one disposable box versus one reusable box. A per-item view helps purchasing compare units but hides how many uses the system actually delivers. Put the comparison unit and baseline side by side.
- Draw the boundary around the processes that could change the conclusion. A factory-only view can isolate a supplier decision; a reuse decision needs return transport, washing, losses, and end of life. A wider boundary asks for more data but exposes burdens moved to another operator or location.
- Separate impact categories rather than collapsing water, energy, and waste into a single claim. Use contrasting scenarios for assumptions like return rates or wash loads. This makes uncertainty visible but may leave a choice between competing priorities instead of a clear recommendation.

## Typical mistakes & examples

Treating a container's rated lifetime as its actual reuse count makes each trip look cheaper environmentally on paper, even when boxes go missing. Ask the operator for observed returns, losses, and wash loads; keep those variables open in the comparison until data exist.

## Deliverables & questions for the human

Show the boundary diagram, comparison assumptions, and data needs by owner. Operations teams and suppliers provide production inputs; a life-cycle assessment specialist determines which comparisons the data support. Which service and baseline should the comparison represent? Where does the system run, and who records actual use and disposal?
