# Shared design methods

Use this map when authoring an entry. Paths are relative to the skill base. Module names below are the stems of `references/<name>.md`. Each mapping is a candidate link, not a runtime reading list: once the card exists, link at the step that needs it and name why. Unlisted entries need no shared card. In the source notes, `verify` means locate the applicable edition, version, or section before making a version-specific or normative claim.
