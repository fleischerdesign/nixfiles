# Shared design methods

Use this map when authoring an entry. Paths are relative to the skill base. Module names below are the stems of `references/<name>.md`. Each mapping is a candidate link, not a runtime reading list: once the card exists, link at the step that needs it and name why. Unlisted entries need no shared card. Sources and `verify` notes live in each card; this index names the method and the reason to load it.
