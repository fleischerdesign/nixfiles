# Textile

## When to load & job

Use this for a textile concept where motif, repeat, and hand shape the end use. A tiled image can show the pattern; it cannot convey how the cloth bends, feels, or handles. If the main question is how a garment fits, let fashion lead.

## Inputs

Gather intended use, viewing distance, handling and care needs, end-use shapes, swatches, and the chosen supplier's process constraints. Request usable width, repeat options, and color limitations from the mill or printer rather than assuming them. Without those inputs, show comparative scales and a provisional tile; describe hand by reference to a named swatch, not the image.

## Decisions & process

- Use an obvious repeat when rhythm is part of the design. If the surface should read as a field, compare a staggered repeat, which can soften the grid but make matching adjacent panels more involved. Show several tiles together and then crop them to the actual end use.
- A directional motif can give a curtain a clear top and bottom; a non-directional arrangement gives a cutter more freedom to rotate pieces but gives up that visual orientation. Overlay likely cutting or panel shapes without estimating yield from an assumed width.
- If a cloth should fall in soft folds, start the hand discussion with a pliable swatch. If the surface needs definition across a broad panel, compare a firmer reference. Put the pattern study beside both: the same motif can read differently when it breaks across tight folds.

## Typical mistakes & examples

A single tile looks balanced on screen → repeated on a curtain, aligned dark motifs form unintended stripes that become stronger at a distance → compare a staggered layout across several widths and show it both flat and folded.

## Deliverables & questions for the human

Show the tile, tiled field, end-use crop, and swatch brief. The mill or printer provides a sample on the intended cloth, and the materials team reviews its color and hand. Final repeat dimensions, color matching, and fabric production remain open. Should the pattern read across the room or reward close viewing, and can adjacent panels deliberately interrupt it?
