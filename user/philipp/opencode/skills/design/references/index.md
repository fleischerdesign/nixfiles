# Design skill index

Find the category by the **deliverable**, not the job title. Read the module at the exact path below.
The index is 1:1 with categories; several categories share a module when their decisions, deliverables and evidence are the same.

**Roles:** `Execution` — the agent can produce the artifact. `Prototype` — the agent can produce an executable or visual prototype, not the final production artifact. `Briefing/Review` — the agent can brief, structure and critique, but the next proof belongs to a specialist.
